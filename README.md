# Margin Studio Landing Page

Landing page estatica, minimalista y responsive para presentar una solucion de gestion de colaterales
y llamadas de margen.

## Como verla

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estatico:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Archivos principales

- `index.html`: estructura y contenido de la landing.
- `styles.css`: estilos, layout responsive y sistema visual neutro.
- `script.js`: interaccion del menu movil y ano dinamico del footer.
