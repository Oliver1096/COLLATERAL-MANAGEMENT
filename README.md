# TechConsulting - Sitio Web de Consultoría Tecnológica

Sitio web minimalista para una empresa de consultoría tecnológica con diseño moderno en blanco y gris.

## Características

- ✨ Diseño minimalista y profesional
- 📱 Totalmente responsive (móvil, tablet, desktop)
- 🎨 Paleta de colores blanco y gris
- 🚀 Animaciones suaves y transiciones
- 📧 Formulario de contacto funcional

## Secciones

1. **Inicio**: Hero section con llamado a la acción
2. **Nosotros**: Información sobre la empresa con estadísticas
3. **Servicios**: Grid de 6 servicios principales
4. **Contacto**: Formulario de contacto e información

## Estructura de Archivos

```
/workspace/
├── index.html          # Estructura HTML principal
├── styles.css          # Estilos minimalistas
├── script.js          # Funcionalidad JavaScript
└── README.md          # Este archivo
```

## Cómo usar

1. Abre `index.html` en tu navegador web
2. Navega por las diferentes secciones
3. El sitio es totalmente funcional y responsive

## Personalización

### Colores
Los colores están definidos como variables CSS en `styles.css`:
- `--color-white`: Fondo principal
- `--color-gray-*`: Varios tonos de gris para fondos y texto

### Contenido
- Edita `index.html` para cambiar textos, servicios e información
- Reemplaza los placeholders SVG con imágenes reales si lo deseas

### Funcionalidad del Formulario
El formulario actualmente muestra una alerta. Para integrarlo con un backend:
1. Abre `script.js`
2. Busca el event listener del formulario
3. Reemplaza la lógica con tu endpoint de API
