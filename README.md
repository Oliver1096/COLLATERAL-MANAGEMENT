# NSC Asset Management landing page

Landing page estatica para una empresa de asset management, inspirada en una estetica editorial, simple y premium.

## Archivos principales

- `index.html`: estructura y contenido de la landing.
- `styles.css`: estilos responsive, layout y componentes visuales.
- `assets/nsc-logo.svg`: version vectorial del logo NSC.

## Como verla localmente

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estatico, por ejemplo:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
